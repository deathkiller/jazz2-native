Jazz² Resurrection Content Swapper

Puts the content of your copy of Jazz Jackrabbit 2 into a Nintendo 64, Dreamcast or PlayStation 2 image of Jazz² Resurrection. Everything happens in this browser tab – your files are not uploaded anywhere.

1. Console image

The image built for the console: .z64 for the Nintendo 64, .cdi for the Dreamcast, .iso for the PlayStation 2.

or drop it here

2. Original game files

The Source folder with the files of Jazz Jackrabbit 2 (Anims.j2a, levels, tilesets, music...), or the game folder that contains it. Any supported version works – the Shareware Demo, Holiday Hare ’98, The Secret Files or Christmas Chronicles.

or drop the folder here
